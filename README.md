# 🔎 Crime-RAG: AI Based Forensic Investigation System

## 📌 Project Overview

Crime-RAG is an AI-powered forensic investigation system that helps investigators analyze suspect sketches and retrieve related crime records using Artificial Intelligence, Computer Vision, Retrieval Augmented Generation (RAG), and Knowledge Graph technology.

The system extracts visual features from suspect sketches, searches similar crime cases, retrieves connected information from a knowledge graph, and generates an investigation report using an LLM.

---

## 🎯 Objectives

- Analyze suspect sketches using AI-based image processing.
- Extract facial features such as hair color, face shape, and facial marks.
- Search similar crime records using semantic search.
- Store and retrieve crime relationships using a knowledge graph.
- Generate automated forensic investigation reports.
